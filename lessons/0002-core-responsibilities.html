只记三句话

ConversationManager 是记录本：保存消息、工具结果和 token 状态。
LLMClient 是协议适配器：连接 Anthropic、OpenAI 或兼容 API，并流式返回统一事件。
Agent 是调度循环：读取对话、请求模型、执行工具、写回结果，直到完成。

它们如何配合

ConversationManager
        ↓ 当前消息
Agent → LLMClient → 模型 API
  ↑         ↓ 文本 / 工具调用事件
  └── 执行工具并把结果写回 Conversation

关键边界：LLMClient 不执行工具；ConversationManager 不控制循环；Agent 不关心供应商 API 的具体格式。

情景判断

问题：模型已经要求调用工具，但工具结果没有加入下一轮消息。你应该首先检查哪个对象？
