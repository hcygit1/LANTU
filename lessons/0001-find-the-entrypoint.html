第 1 课：找到程序入口

完成后，你能从终端命令准确找到 LANTU 的启动分支。预计 8 分钟。

一条主线

终端执行 lantu
pyproject.toml 将它映射到 lantu.__main__:main
main() 调用 _main()
_main() 根据参数选择交互、TUI、单次提示或远程模式

亲手验证

打开 pyproject.toml，找到 [project.scripts]；再打开 lantu/__main__.py，找到 _main() 中的三个参数分支：

--tui
-p "提示词"
--remote

思考：执行 uv run lantu -p "你好" 时，最终进入哪个函数？

为什么先学入口

修改功能前，先确定行为属于哪个运行模式。否则很容易改到旧版 TUI，却发现默认内联界面完全没变化。

资料

主资料：项目入口源码。遇到参数解析细节，再查 Python argparse 官方文档。

复习时使用：LANTU 项目地图。
